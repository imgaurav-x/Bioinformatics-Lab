# DNA Toolkit

A beginner bioinformatics project built with Python.

## Features

- DNA Sequence Length
- Nucleotide Count (A, T, G, C)
- GC Content Calculation
- DNA to RNA Transcription
- Reverse Complement Generation

## Example

Input:
ATGC

Output:
Length: 4
GC Content: 50%
RNA: AUGC
Reverse Complement: GCAT


# FASTA Analyzer

A beginner bioinformatics project built using Python.

## Features
- Read FASTA files
- Extract sequence names
- Extract DNA sequences
- Calculate sequence length
- Calculate GC content

## Example Input

>DNA_Sequence_1
ATGCGCGCATATATAT

## Example Output

Sequence Name: DNA_Sequence_1
Length: 16
GC Content: 50.0%
